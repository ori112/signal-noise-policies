Privacy Policy

Last updated: 2026-10-24

This policy covers a personal software tool used to manage and upload videos to a single YouTube channel, "Signal & Noise." The tool is built and operated by its owner, for that owner's own use. It is not distributed to the public and does not have other users.

What it accesses

The tool connects to the YouTube Data API and YouTube Analytics API using the owner's own Google account credentials. Through those APIs it can:

  • Upload videos and set their title, description, tags, and thumbnail
  • Read and reply to comments on the owner's own videos
  • Read view counts, watch time, and revenue data for the owner's own channel

What it does with that data

All data read from these APIs is stored locally on the owner's own computer, for the owner's own use in planning and improving their channel. None of it is sold, shared, or sent to any third party.

Third-party services

The tool also uses paid APIs for generating images, video clips, and narration (such as fal.ai, ElevenLabs, and Higgsfield). Script text and visual prompts are sent to these services to generate assets for videos. No YouTube viewer or commenter data is sent to them.

YouTube API Services

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service and acknowledges the Google Privacy Policy.

Data deletion

The owner can revoke this tool's access at any time from the Google Account permissions page, which immediately stops any further API access. Any locally stored data read from the APIs can be deleted by deleting the tool's local files; nothing is retained on any server the owner doesn't control.
